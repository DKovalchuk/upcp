# TASK-0094: S16.1 — Performance & Accessibility

Sprint: S16.1
Milestone: M14 (0.16.0)
Branch: `feature/S16.1-perf-a11y`
Points: 8

## Items

### 4.1 — Bundle Splitting (lazy routes)
- Wrap all page routes in `React.lazy()` + `<Suspense>`
- Routes: Dashboard, ProjectList, ProjectDetail, DeliveryPage, QualityPage, AuditPage, ReportsPage, HealthPage, SettingsPage, GitIntegrationPage
- Add loading fallback (PageSkeleton)
- Verify bundle size < 300KB after split

### 4.2 — staleTime for React Query
- Audit all `useQuery` / `useQueries` / `useInfiniteQuery` calls
- Add `staleTime` per data type:
  - Static/slow-changing (components, modules): 5 min
  - Dynamic (tasks, features, dashboard): 30s
  - Real-time (heartbeat, claims): 0 (default)
- Add `gcTime` for garbage collection tuning
- No unnecessary refetches on window focus for stable data

### 4.3 — BoardView Single /tasks Endpoint
- Backend: ensure `/projects/{id}/tasks` supports all needed filters (status, feature_id, assignee)
- Frontend: replace `useQueries` (N parallel feature queries) with single `useQuery` to `/projects/{id}/tasks`
- Parse results into board columns client-side
- Verify same data, fewer network requests

### 5.1 — aria-labels on Icon-Only Buttons
- Audit all `<Button>` with only icon children (no visible text)
- Add `aria-label` to each
- Components: TopBar, DataTable pagination, TaskDetailSheet tabs, CommandPalette, ProjectDetail header, etc.

### 5.2 — Touch Targets ≥ 44px
- Audit all clickable elements (buttons, links, tabs, toggles)
- Minimum 44×44px touch target
- Use `min-h-[44px] min-w-[44px]` or padding where needed
- Priority: mobile-visible elements (nav, toolbar, cards)

### 5.3 — Horizontal Scroll Hints on Tables
- Add visual scroll indicator (fade/shadow) on tables wider than viewport
- Components: ProjectTable, task tables, audit timeline, reports
- CSS: `overflow-x-auto` with gradient fade on right edge when scrollable
- Responsive: hide hint on desktop, show on mobile/tablet
