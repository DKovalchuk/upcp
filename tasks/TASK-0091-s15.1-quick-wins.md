## Risks

1. **OpenAPI docstrings may be verbose** (2.8): FastAPI docstrings go directly into OpenAPI spec. Keep them concise. **Mitigation**: Use `summary` for one-liner, `description` for details.

2. **Settings page scope creep** (2.10): Could grow into full settings page. **Mitigation**: MVP — theme, API URL display, version. No auth/settings integration.

3. **useProjectId hook might not work in all contexts** (3.2): Some components might need projectId at render time differently. **Mitigation**: Hook uses `useLocation` which is available in all router-managed components.

4. **Dead code sweep may miss things** (3.5): Comprehensive sweep takes time. **Mitigation**: Focus on high-confidence items (unused imports, local duplicates). Don't chase marginal cases.
